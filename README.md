## 📋 About the System

**BCC Scan2Fetch** is a **Student Release & Pickup Management System** designed for schools. It ensures that only authorized guardians can fetch students from school using QR code scanning and authorization letters.

---

## ✨ Features

- 🔐 **Multi-Role Login** (Admin, Staff, Parent)
- 📊 **Role-Based Dashboard** with real-time statistics
- 👨‍👩‍👧 **Parent Management** with QR Code generation
- 👨‍🎓 **Student Management** with photo upload
- 👨‍💼 **Staff Management**
- 📸 **Camera Capture** — Take photo or upload
- 📷 **QR Code Scanner** — Camera + Manual input
- 📝 **Authorization Letter** — Parent sends, Staff approves
- 📱 **SMS Notification** — Auto-send on student release
- 📋 **Activity Logs** — Track all system actions
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile

---

## 🛠️ Tech Stack

- **Backend:** CodeIgniter 4 (PHP)
- **Frontend:** AdminLTE 3, Bootstrap 4, jQuery
- **Database:** MySQL
- **QR Code:** PHPQRCode
- **Camera:** HTML5 getUserMedia API
